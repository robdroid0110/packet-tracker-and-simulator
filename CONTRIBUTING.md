# Contributing

Packet Tracker and Simulator welcomes fixes and independently developed networking features.

Before contributing, run `python3 -m unittest discover -s tests -q` and keep the GUI and machine-readable agent API behavior aligned. Include regression tests for engine or interface changes.

Submit original source and redistributable assets only. Do not add images, executables, proprietary help files, sample lab files or extracted content from other commercial network simulators. Preserve existing third-party notices, including the decoder's MIT license.

Use an issue to discuss significant architectural changes before opening a pull request. Keep each change focused and document feature limitations accurately.
