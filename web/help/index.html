Packet Tracker and Simulator — Help

An independent local network simulator for configuring and testing virtual topologies. Hardware and protocol behaviour may be simplified.

Getting started

Choose a device in the tray, then click or drag it onto the Logical canvas. Select Connections to connect free network ports. Click a device to open its configuration and physical views.

Device configuration

The catalogue marks engine-backed and simplified models. Use the Config or CLI tab to configure supported networking operations. Unsupported actions are not presented as successful.

Simulation and traffic

Switch between Realtime and Simulation modes in the control panel. Use capture filters and step/play controls to inspect generated events. These are deterministic network-model traces, not wire-accurate captures.

Projects and imports

File → Save produces a native JSON lab; File → Open loads one. The optional legacy .pkt importer supports a subset of another simulator's file format and reports limitations. .pka and .pkz are not supported.

Keyboard shortcuts

Tab/Shift+Tab navigates controls; Enter/Space activates them; Escape closes dialogs. On the Logical canvas, Shift+D focuses a device; Arrow keys navigate; Shift+Arrow moves a device; Enter opens it.

Preferences

Options → Preferences contains display, accessibility and simulation settings. Browser preferences stay in local browser storage. Lab state is saved separately.

Agent interface

The Agent Shell shares the GUI's simulator state. Type help in the shell. Discover machine-readable commands using /api/capabilities.

See the repository's README and documentation for more details, current limitations and supported operations.
