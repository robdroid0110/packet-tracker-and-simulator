# Original mixed-network audit projects

Use **File → Open** on `campus.json`, `branch.json`, or `industrial.json`.
They are independent native Packet Tracker and Simulator labs. Open replaces the current
workspace after confirmation and creates a backup; undo restores the prior lab.

[Feature coverage](../../HELP_COVERAGE.md) describes the actual
services, fault scenarios, limits, and how to regenerate these examples.
