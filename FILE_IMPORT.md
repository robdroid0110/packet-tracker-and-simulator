# Opening and saving labs

Use **File → Open** or the Open toolbar button to choose a `.json` or `.pkt` file from your computer. Packet Tracker and Simulator first parses the file and shows the device and link counts and any import warnings. Confirm to replace the current lab; the server saves a backup first. Cancel or a failed import leaves the current lab unchanged. **File → Save** downloads the current lab in Packet Tracker and Simulator JSON format; the Linux desktop presents a save dialog.

legacy network simulator `.pkt` is a different, encoded file format from Packet Tracker and Simulator JSON. The importer supports both older numeric and newer saved-reference device identifiers. It translates device names, supported models, logical positions, copper and selected serial, phone, coaxial and fiber links, host IPv4 addresses, gateways and DNS, the wireless controller management address mapped to its physical port, and a subset of router and switch running configuration, including IPv4 addressing, shutdown state, access VLANs, static routes and OSPF networks. Original IOS running-config text up to 200 KB per device is retained in that device's `config.packet_tracer_running_config` attribute; retaining text does not make an unsupported command operational. An imported lab is a conversion into Packet Tracker and Simulator's own simulation, not a legacy network simulator runtime.

**The conversion is partial.** Many IOS commands, services, protocols, VLAN features, modules, cable types, activities, drawings, custom art and the physical workspace may be lost or differ. Unsupported models and links are reported, but not every unsupported vendor setting can be individually detected. Names that the simulator cannot use are changed and reported. Some file versions and complex labs cannot be imported. Imported links retain their saved cable types and interface shutdown state; the simulator may show links down when those settings or its media model do not produce carrier. Always keep the original `.pkt`, read the preview and verify the converted lab. There is no `.pkt` export, and `.pka` activities are not supported. Files are limited to 8 MB and decoded documents to 32 MB.

Agents can use `POST /api/lab/import` with JSON `{ "filename": "lab.pkt", "data": "BASE64_CONTENT", "commit": false }` to preview counts and warnings. Set `commit` to `true` to import and receive the new `state` and `safety_backup` name. The backup can be restored through `POST /api/backups/restore` with `{ "name": "..." }`. Existing `GET /api/state` exports the current Packet Tracker and Simulator JSON lab.

The decoder in `netsim/pkt_codec` is adapted from [Unpacket](https://github.com/Punkcake21/Unpacket) under the MIT license; its copyright and license are in `netsim/pkt_codec/LICENSE`. No vendor sample lab or proprietary artwork is distributed with the importer.
